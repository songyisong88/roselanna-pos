# ROSELANNA — เดโมระบบจองคิว / POS / แดชบอร์ด (ข้อมูลตัวอย่าง)

เดโมแบบคลิกเล่นได้ ไม่มี backend ไม่มีการเชื่อม LINE จริง ไม่มีการชำระเงินจริง ไม่เรียกเครือข่ายภายนอก
ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่าง เก็บใน localStorage ของเบราว์เซอร์

- เปิด `index.html` ได้โดยตรง หรือเสิร์ฟด้วยเว็บเซิร์ฟเวอร์ใดก็ได้ (`python3 -m http.server`)
- มุมมอง: ฝั่งลูกค้า (LINE) · POS หน้าร้าน (แท็บเล็ต) · แดชบอร์ดเจ้าของ — สลับจากแถบด้านบน
- สิทธิ์ผู้ใช้จำลอง 4 แบบ: เจ้าของ / ผู้จัดการสาขา / แคชเชียร์ / หมอนวด
- ปุ่ม "รีเซ็ตข้อมูลเดโม" อยู่ท้ายหน้าแดชบอร์ด
- ทดสอบ: `node tests/e2e.js http://localhost:PORT/index.html` (ต้องมี Playwright)
- `build_assets.py` สร้างโลโก้ SVG และฟอนต์ Sarabun (self-host)
